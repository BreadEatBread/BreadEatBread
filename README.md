## 🛠 지금 하는 일

**React·Django 풀스택 개발자**입니다. 화면 설계부터 API·데이터 모델링까지, 제품의 앞뒤를 함께 다룹니다.

- 🖥 **엔터프라이즈 프론트엔드** — 조직도·권한·전자결재·그리드·게시판 등 성격이 다른 화면을 폭넓게 (React · Ext JS · SlickGrid)
- 🧩 **SaaS 백엔드** — 멀티테넌트 MES의 생산·재고·설비·KPI 기능과 데이터 격리·권한 처리 (Django · PostgreSQL · Docker)
- ⚙️ Celery 기반 KPI 집계 파이프라인, AWS EC2 운영 배포

> **굿스트림**에서 2년간 엔터프라이즈 프론트엔드를 개발했고, 지금은 **서울소프트**에서 SaaS MES의 프론트·백엔드를 함께 맡고 있습니다.

## 🔩 남들이 멈추는 곳까지 — 하드웨어

풀스택으로 데이터를 쫓다 보면 결국 그 **출발점인 기계 앞**에 서게 됩니다.
남들이 "여기부터는 하드웨어 담당"이라며 멈추는 지점에서, 저는 납땜하고 시리얼 모니터를 들여다보며 데이터의 첫 구간까지 직접 만듭니다. 소프트웨어를 메인으로 두되, 필요하면 센서 앞까지 내려갈 수 있다는 게 제 차별점입니다.
